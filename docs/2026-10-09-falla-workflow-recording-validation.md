## 改动与兼容边界

- coordination 给出通用完成/验证、single、parallel、基线及异常恢复的章节入口。普通 single 仍加载基线检查，
  跨 change 依赖、旧记录、已有子映射或证据变化时追加对应章节，不能按默认模式省略这些规则。
- Propose/Apply 通过 coordination 的导航加载适用章节；规则不复制到 Skill 或 Schema，不新增 profile 或配置开关。
- handoff 保持同一个记录，当前 task 只更新增量。有效的已完成证据保留简短摘要或准确的项目内引用，
  事实、设计和 Rule ID 不反复复制全文；引用变化、不可访问或证据失效时重新核对。
- 注释审计只覆盖本 task 新增/实质修改符号；生命周期收尾按规划 task 执行，普通 task 记录自身引入的风险。
  未运行、待收尾和不适用分别写明，不能把轻量检查写成构建通过或无泄漏。
- 父子 comate 的字段名称、缩进层级、format-version: 2、默认模式和待认领状态保留。
  未修改任务编号、Schema DAG、comate 解析器、认领锁、基线或归档实现，Apply 仍每轮一个 task 后暂停。
- README 与安装手册只增加日常导航；新增 docs/README.md 作为历史设计、计划和审计入口，标明按日期/提交适用，
  不重写历史记录或真实项目的既有 tasks/comate。

## 增量填写走查

以下为合成文档任务的写法，不是实际业务代码、用户验收或模型独立采样。完整模板字段保留，这里只摘录主要内容：

```text
- 交接 (handoff):
  - 当前任务：2.1 文档收尾
  - 已确认事实与关键决策：见 design.md「范围」，本次无变化
  - 注释审计：2.1 仅文档改动，无新增或实质修改代码符号
  - 已完成：1.1 保留已验证摘要；2.1 指引与当前字段一致
  - 验证证据：1.1 原检查结果仍适用；2.1 合成文本对照完成，无构建影响
  - 安全与敏感信息结论：本次仅合成文档，无敏感正文，无运行时代码改动
  - 下一步准确操作：全部任务完成，等待用户决定下一阶段
  - 遗留风险与恢复条件：未做运行验证；新增代码或输入变化时重新规划与复核
```

父子模板分别填入这一类摘要后，由现有解析与完成门禁校验；同时逐项清空五个必需证据字段，确认仍拒绝完成。
任务未完成、人工结果 pending 或总人工状态未通过的记录也仍被拦截。这里只证明格式兼容和门禁未放宽，
程序不会核实引用内容、自然语言结论或验收真实性。

## 潜在风险

- 按场景导航仍依赖 Agent 正确识别模式、旧记录和依赖；不能只读 single 章节就跳过通用与基线规则。
- 短 handoff 可能丢失前序任务证据或引用过期结论，必须保留有效摘要并核对引用；格式通过不能证明语义完整。
- 待收尾任务不能写成生命周期已验证；真实释放、NPE 与安全边界仍需按实际代码及验证条件检查。
- 此次未做真实 Android Apply 试跑或独立模型评估，不宣称已证明阅读量或填写时间下降。
- 外部安装副本需走 install/doctor 更新并重开 Agent 会话；不重写已有 change 或刷新旧完成基线。
