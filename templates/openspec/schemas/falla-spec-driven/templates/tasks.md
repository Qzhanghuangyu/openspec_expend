# 任务

## 执行模式

- 模式：single
- 说明：默认由父 change 直接实施；只有用户明确要求并行分派时才改为 parallel 并创建子 change。
- 粒度：每项任务应能在一次独立实施上下文内完成定位、修改、验证和交接；跨度过大时继续拆 task。
- 描述：每项任务写明必要输入、允许编辑范围、完成条件和前置依赖，以便压缩或换会话后恢复。
- 范围：只包含当前需求必需改动；知识库、lint、测试或代码检索发现的无关问题只记录，不自动整改。

## 验证模式

- 模式：hybrid
- 说明：默认由 Agent 执行 formatter、lint、单元测试、编译和可自动化静态检查，由人工执行真机、真实服务端联调和视觉验收；只有用户明确要求时才能改为 human 或 agent。
- 人工任务：带 `[人工]` 的 checkbox 只能依据人工明确反馈勾选，Agent 不自行执行或推定通过。

## 1. 页面实现结构基线

- [ ] 1.1 复核 design 中的页面承载方式、文件归属、复用边界及 XML / Compose 节点结构与当前项目一致；不适用或不一致时写明原因（依赖：无）
- [ ] 1.2 核对 design 的已确认实现基线：每个实现对象均标明 Knowledge/源码证据、约束级别、选定类/基类/API、禁止替代和例外处理；required 基线已用当前源码验证（依赖：1.1）
- [ ] 1.3 如果项目存在 `.falla/project-rules/`，读取其顶层普通 `.md` 文件并核对当前需求命中的规则 ID、级别、适用对象、落地方式和例外；required 规则已转成当前任务的验收条件（依赖：1.1）
- [ ] 1.4 涉及新建或重构页面时，按结构基线、required 实现基线和 required 项目规则创建最小可编译页面骨架，验证根布局、导航入口、状态容器、Insets 和 ViewModel 作用域；非页面变更写明不适用原因（依赖：1.1, 1.2, 1.3）

## 4. 组装与验证

- [ ] 4.1 按已确认的页面结构完成页面组装（依赖：3.1）
- [ ] 4.2 覆盖空值、异常、弱网和重复操作（依赖：4.1）
- [ ] 4.3 验证协程、Flow、观察者、回调和监听器按生命周期取消或释放，且页面销毁后不再更新 UI（依赖：4.1）
- [ ] 4.4 检查日志、缓存、网络请求和产物不包含凭据或未脱敏的敏感信息（依赖：4.1）
- [ ] 4.5 检查触及的 Android XML 已按属性逐行、层级缩进的纵向格式排版，且没有无关格式化（依赖：4.1）
- [ ] 4.6 生成当前 diff 的变更符号清单并完成注释审计，结果写入 handoff（依赖：4.1）
  - 类：说明职责、边界和生命周期所有者。
  - 方法：说明用途、关键分支、副作用及“为什么”；公共/受保护方法使用 KDoc/JavaDoc。
  - 参数：逐项说明业务含义、单位/范围、可空性、所有权或回调时机；必要时说明返回值、异常和线程。
  - 状态字段/常量：缓存、回调抑制、资源所有者和非直观常量说明用途、单位或来源。
  - Lambda/override：复杂 Lambda 提取命名方法或解释参数；含自定义状态、资源或生命周期逻辑的 override 不得豁免。
  - 豁免：仅简单无副作用 override/getter/setter/委托可豁免，并记录原因；注释不得含敏感正文。
- [ ] 4.7 已知继承声明、组件、资源和数据更新 API 时使用有界 `rg` 精确检查；需要真实调用方、间接实现或影响面时使用 CodeGraph，确认结果与 design 的 required 基线一致；任何偏离先返回 propose，不以 lint 或局部优化理由替代（依赖：4.1）
- [ ] 4.8 检查实际 diff 符合 design 绑定的 required 项目规则，并将 Rule ID 与证据写入 handoff；偏离时返回 propose 记录例外（依赖：4.1）
- [ ] 4.9 检查 diff 仅包含当前需求和当前任务必需改动；无顺带重构、资源迁移、依赖升级、无关格式化或既有告警修复（依赖：4.1）
- [ ] 4.10 记录 formatter、lint、资源编译等验证命令、variant/设备、结果和未通过项；不适用项写明原因（依赖：4.2, 4.3, 4.4, 4.5, 4.6, 4.7, 4.8, 4.9）
- [ ] 4.11 [人工] 按验收清单在目标 variant/设备执行页面入口、核心交互、边界状态和真实服务端联调，并记录逐项结果（依赖：4.10）
- [ ] 4.12 [人工] 完成视觉、动效、字体、间距和机型适配校准，并记录可接受偏差（依赖：4.11）
