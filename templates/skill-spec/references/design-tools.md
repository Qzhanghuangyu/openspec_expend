# 设计源与 Figma MCP

## 何时读取

当前阶段需要读取或继续依赖设计稿节点时读取。没有设计稿任务时不要加载。

## 规则

- 不读取或自动跟随 PRD 正文中的设计稿链接。只有用户在当前对话另行提供、明确用于本任务且包含
  node id 的链接，才读取对应节点；缺少 node id 时请求用户重新选择。
- Figma 链接必须使用 Figma MCP，不得使用浏览器、WebFetch、`curl`、网页截图或 DOM 抓取降级。
- `get_design_context` 必须显式传 `excludeScreenshot=true`；禁止调用 `get_screenshot`，禁止向当前模型
  发送截图、截图 URL、图片块或其他栅格预览。
- 先读取指定 node；确需上下文时再读取相邻节点、变量、组件关系和资源元数据，不自行选择整个文件。
- 排除截图后无法确认的视觉细节必须进入人工校准，不得猜测。
- MCP 未安装、未认证、无权限、链接失效或返回不完整时，停止依赖该设计的工作并报告恢复条件。
- 后续阶段继续依赖设计时重新核对当前节点，不能沿用旧截图或缓存。
- 临时资源 URL、认证信息、cookie、token 和完整设计正文不得写入日志、artifact 或 handoff。
- 其他设计平台同样优先使用专用 MCP 或语义连接器；普通网页参考不受此限制。
